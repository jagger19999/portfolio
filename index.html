02

多模态数据接入与毫秒级同步

目标

将驾驶行为、眼动与生理信号映射到同一时间基准，实现跨设备毫秒级时间戳对齐，并支撑事件级行为分析。

完成

  • 构建统一时钟与事件总线，将 ECG、EDA、眼动、驾驶任务日志按统一时间轴对齐，支持异步采样率融合。
  • 在采集端完成事件触发打标（如突然风险、接管、警报提示），并将事件窗口回写到多模态数据切片。
  • 形成"时间戳对齐 → 事件窗口抽取 → 指标聚合"的分析闭环，显著降低人工对帧与手工标注成本。

03

行为分析与研究支持

目标

围绕关键驾驶指标，结合眼动、心率、心率变异性及皮肤电等多模态数据，开展核心指标的对比统计分析与结果解释，提升驾驶行为研究的可解释性。

完成

  • 围绕速度控制、车道保持、操作反应等关键驾驶指标，结合眼动、心率、心率变异性及皮肤电等多模态数据开展联合分析。
  • 基于 Python 数据分析库进行核心指标的对比统计，并结合方差分析、T 检验等方法对实验结果进行显著性验证。
  • 结合驾驶行为表现与生理心理指标变化，对实验结果进行解释，为课题假设验证与研究结论形成提供支持。

会议现场

会议现场

成果

研究《中央绿化隔离带对高速驾驶警觉度的影响：基于注视熵的眼动证据》于中国心理学会眼动心理学术年会完成口头汇报。

目标

总结中央绿化隔离带对高速驾驶警觉度的影响，基于注视熵等眼动指标形成研究结论并完成学术交流。

关键结果

绿化隔离带条件下，驾驶员的静态注视熵与动态注视熵均更高，表现出更广泛、灵活的视觉搜索模式，提示其在长时高速驾驶过程中维持了更高水平的驾驶警觉度。
