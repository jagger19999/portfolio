# 三类眼动案例底图

三个页面均按 1920×1080 设计，无需滚动，建议使用浏览器全屏呈现。

- `commerce.html`：电商商品详情页。主要兴趣区为价格、促销、配送退换、型号说明与购买按钮。
- `cockpit.html`：真实数字座舱。主要兴趣区为仪表盘、中控屏、方向盘按键与中央控制区。
- `game.html`：游戏视觉引导。主要兴趣区为石门、符号、钥匙、任务提示和视觉干扰。

采集前请固定浏览器缩放为 100%，显示分辨率为 1920×1080。后续导出的热力图、扫视路径和 CSV 应保留与底图相同的案例名称。
